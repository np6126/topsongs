For concert prep: one concert or a mix of the last concerts from setlist.fm as a playlist. In a mix the most played songs come first. Only creates, never deletes.

Purge

Deletes all playlists of the nightly run, or all with a name prefix — across all users. Never live playlists. Preview first, then run it deliberately.

Prune

Keeps only the named playlists and deletes all others. Kept ones can be renamed with a prefix.
